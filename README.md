# つくって学ぶWeb基礎

「Web制作の基礎」の学習サイトと教材です。サイトの中で基本のやり方を試し、自分のPCの VS Code と Chrome で同じことを作ります。

## 学習サイト

https://abogadoatusi.github.io/web-basic/

生徒に渡すのは、このURLだけで足ります。教材ZIPはサイトの右上から保存できます。

以前に開いたことがある場合、古い内容がブラウザに残ることがあります。`Ctrl+Shift+R`（Mac は `Cmd+Shift+R`）で読み込み直してください。

## 使い方

1. 学習サイトを開く（上のURL、または手元の `index.html`）
2. サイト右上の「教材ZIPを保存」から `web-kiso-kyozai.zip` を保存して展開する
3. `lesson-01-tools` から順に、各フォルダの `my-site` を VS Code で開いて進める
4. `index.html` を Chrome で開いて確かめる（保存したら再読み込み）

VS Code のインストールと日本語化の手順は、レッスン1の中にあります。生徒側に事前に必要なのは Chrome だけです。

## ひみつの仕掛け（先生向け）

サイトには仕掛けが3つ隠れています。画面にカウンタは出さないので、知らないと気づきません。

| | 仕掛け | 起こし方 |
| --- | --- | --- |
| ① | 画面に虹が出る | コードを1行コメントアウトする |
| ② | 画面が揺れる | 閉じタグを付け忘れる |
| ③ | 見えない文がコピーに付いてくる | レッスン本文をコピーする |

③は、コピーした文章をメモ帳に貼ると、画面に出ていなかった文が付いてきます。ここは毎回確実に動きます。

その隠し文には、AIへの指示が書いてあります。拾った文章をそのままAIに渡すと、自分が読んでいない命令も一緒に渡る、という実演です（プロンプトインジェクション）。ただし対策済みのAIは従いません。**従わないのが正常な結果**なので、「このAIは対策できている」という見せ方にしてください。
