# つくって学ぶWeb基礎
 
「Web制作の基礎」の学習サイトと教材です。サイトの中で基本のやり方を試し、自分のPCの VS Code と Chrome で同じことを作ります。
 
## 使い方
 
1. 学習サイト（`index.html`）を開く
2. サイト右上の「教材ZIPを保存」から `web-kiso-kyozai.zip` を保存して展開する
3. `lesson-01-tools` から順に、各フォルダの `my-site` を VS Code で開いて進める
4. `index.html` を Chrome で開いて確かめる（保存したら再読み込み）
## 個人情報について
 
- 学習サイトの中に書き込む名前・住所・メールなどは、**ダミー（うその情報）で大丈夫**です
- 自分のPCで作るもの（`lesson-13-final` など）は、そのまま自分のホームページとして使えます。公開するときは、載せる個人情報をよく考えて決めましょう
- 学習サイトは、書いた内容を外部へ送りません。保存は自分のブラウザの中だけです
